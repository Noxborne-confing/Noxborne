مرورگر به API کلادفلر دسترسی نمی‌ده. لطفاً فایل رو روی یه سرور بذار (Netlify, GitHub Pages) یا از حالت دستی استفاده کن.
🤖 حالت خودکار (API)
✍️ حالت دستی
💡 مراحل:
۱. توکن API از dash.cloudflare.com/profile/api-tokens بساز
۲. با دسترسی: Workers Scripts:Edit + Workers KV:Edit + Account Settings:Read
۳. اینجا پیست کن و دکمه رو بزن
✅ این حالت هیچ API نمی‌خواد! Worker رو خودت توی پنل کلادفلر می‌سازی.
بعد فقط URL و کلید رو اینجا وارد می‌کنی.
۱
برو به dash.cloudflare.com → Workers & Pages → Create Worker
۲
اسم بذار noxborne-sub و کد Worker رو پیست کن (از دکمه پایین کپی کن)
۳
برو به Settings → Variables → KV namespace بساز به اسم NOX_KV و Bind کن
۴
Environment Variable بساز به اسم ADMIN_KEY با هر مقداری که می‌خوای (مثلاً mahan183836)
۵
Deploy کن و URL Worker رو اینجا وارد کن
